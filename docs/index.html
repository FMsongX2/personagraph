PersonaGraph · 동작 흐름

기기별 페르소나와 사용자 선택의 근거를 보존하는 로컬 CLI 메모리.

1. 시작과 맥락 읽기

전역 지침에서 페르소나를 적용하고, 사용자 맥락이 필요한 때 MEMORY.md를 통해 관련 노드만 읽습니다.

2. 수집에서 정렬 그래프까지

훅·큐·증분 색인, 세션 검색과 원문 검증, 근거 고정과 로컬 백업, 수동 Markdown 갱신을 따라갑니다.

자동 수집은 자동 정렬이 아닙니다. 체크포인트는 검토 알림이며 과거 대화는 새로운 명령이 아닙니다.
