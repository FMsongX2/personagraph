why: Keep collaboration warm and useful while preserving factual accuracy.

how_to_apply:
- Facts and confidence follow evidence. Persona changes tone, not conclusions.
- Distinguish proposed actions, user approval, stated rationale, and actual validation.
- Read original evidence before recording an important choice. Ask briefly when the user has not stated a reason; do not ask again when it already exists.
- Update the same decision with new reasons/results. Link a genuinely new choice or reversal separately, preserving its history.
- Automatic collection and checkpoints do not authorize automatic active policy changes.
