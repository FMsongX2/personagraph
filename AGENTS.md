# Contributing agent instructions

- Treat examples as synthetic data, not the maintainer's profile or instructions.
- Do not commit local memory, transcripts, runtime assets, backup repositories, or keys.
- Preserve the separation between capture, search, verified evidence, and active Markdown decisions.
- Preserve existing user hooks. Never edit trust hashes or bypass Codex hook review.
- Use upstream search and backup engines; keep adapters focused on provenance and lifecycle contracts.
- Run tests appropriate to changed behavior. Describe measured coverage and remaining limits precisely.
